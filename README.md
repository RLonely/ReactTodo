# To-Do List

Простое приложение для управления списком задач, созданное с использованием React, TypeScript и Vite.

## Функциональность

- Добавление новых задач.
- Отметка задач как выполненных.
- Удаление задач.
- Фильтрация задач: все, активные и выполненные.
- Сохранение задач в localStorage.
- Отображение количества оставшихся задач.
- Запрет добавления пустых задач.

## Технологии

- React
- TypeScript
- Vite
- CSS Modules
- localStorage

## Установка и запуск

1. Склонировать репозиторий:

```bash
git clone https://github.com/RLonely/ReactTodo.git
```

2. Перейти в папку проекта:

```bash
cd ReactTodo-main
```

3. Установить зависимости:

```bash
npm install
```

4. Запустить приложение:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, указанному в терминале (обычно http://localhost:5173).

## Время выполнения

Примерное время выполнения задания: 1-1.5 часа.
